# Sample Project

## Initial Thoughts on Project Creation

Website (endpoint) to use for this sample: [https://dummyjson.com](https://dummyjson.com)

## Notes

- The project is stateless; all data is provided by dummyjson.com.
- The API will primarily be used for the following features:  
  0. Splash Screen
  1. User Login
  2. Bottom Navigation Bar (User, Product, Home, and Settings)
  3. CRUD operations with products
  4. REST API use cases with (GET, POST, PUT, DELETE)

The idea is to possibly use clean architecture in the project.
